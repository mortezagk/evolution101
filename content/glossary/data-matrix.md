<div class="term-translation" markdown="1">
در فیلوژنتیک، مجموعه‌داده‌ای متشکل از فهرستی از تاکسون‌ها و مجموعه‌ای از صفات آن‌ها (که [ویژگی]({filename}character.md) و حالت‌های ویژگی نامیده می‌شوند). از ماتریس‌های داده برای ساختن درخت‌های فرگشتی استفاده می‌شود. برای نمونه، ماتریس دادهٔ یک فیلوژنیِ سوسک‌ها ممکن است فهرستی از گونه‌های سوسک باشد و بسیاری از ویژگی‌های آن گونه‌ها را مشخص کند — اینکه هر کدام چند بندِ شاخک دارد، کدام‌ها بال خال‌دار دارند و کدام‌ها بال یکدست، و جز آن. ماتریس‌های داده می‌توانند توالیِ ژنتیکیِ یک ژن مشخص یا بخشی از ژنوم را هم در بر بگیرند.
</div>

<div class="term-original" lang="en" dir="ltr" markdown="1">
In phylogenetics, a data set that consists of a list of taxa and a set of those taxa’s attributes (called [characters]({filename}character.md) and character states). Data matrices are used to build evolutionary trees. For example, a data matrix for a beetle phylogeny might consist of a list of beetle species and would specify many traits of those species—how many antennal segments each has, which have spotted wings and which have solid wings, etc. Data matrices can also include the genetic sequence for a particular gene or part of the genome.
</div>
